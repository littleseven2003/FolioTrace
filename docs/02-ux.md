# 交互与视觉规格

## 页面

项目首页：最近项目、打开文件夹、新建文件夹、待处理数量。原型只覆盖单个项目主界面；首页在 M2 补齐。

项目内左侧：产出材料 / 全部文件 / 项目总览 / 待处理；参考、过程、排除筛选；Agent 协作约定。主区显示材料卡、时间线、右侧版本信息。总览是独立入口，不挤进文件表格。

## 图谱

每个逻辑 documentId 一条稳定色带，不按扩展名赋唯一色。实线 child.parentVersionId；虚线 fromVersionId -> toVersionId。时间由新到旧；默认等距排序，不能暗示线段长度代表实际时间。分支允许共用父节点，首版不支持多父合并。排序用 ISO 时间，再用 versionId 做稳定次序。

同一时间多节点不重叠；节点有材料名、版本标签、时间与状态。颜色以外还提供文本、形状和线型区分。节点支持键盘 Enter/空格、可见焦点。支持搜索淡化、关闭配套线、突出选中节点及配套；点选显示摘要及实际文件，关系不会因最新版本改变而漂移。

首版默认 200 节点视图，超过时提示时间范围筛选并显示总数；不要无提示截断。节点坐标可缓存但不保存为领域数据。

## 任务面板

选择材料 -> 基础版本（默认当前采用）-> 本次参考资料（默认不勾选全部）-> 编写要求 -> 配套范围 -> 保存任务并复制指令。未分类或 excluded 不可默认加入参考；用户显式覆盖时记录确认。无当前采用版时必须选版或选择创建初稿。

## 待处理

未登记文件、记录错误、文件丢失、内容漂移、配套需核对集中展示。提示给出可执行的“修正记录 / 指定用途 / 重新定位 / 复制补写指令”。业务异常不能仅以 toast 消失。

## 写作流程说明

保留原型五步互动分镜：整理材料 -> 定义任务 -> Agent 编写 -> 工作台接收 -> 用户采用。按步骤展示输入、动作和产出，不做虚假运行状态。可从分镜进入创建任务。

## 视觉约束

桌面三栏，窄窗口改为上下布局；主体至少 1000×700 可用，小宽度图谱横向滚动。主色静谧蓝，材料色与主题强调色独立。Lucide 本地 SVG；纯净、雾色、山影、点阵背景只作用底层，卡片保持对比度。悬停微动效不循环，尊重系统减少动态效果。焦点捕获与 Escape 关闭、中文长路径换行、空/加载/错误态必须齐全。

原型具有模拟数据、固定坐标和浏览器设置保存；真实程序必须用类型化模型驱动，禁止把单文件脚本整体当生产组件。外观偏好保存在应用设置，不进入每份业务项目。
