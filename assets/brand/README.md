SVG 是工程母版，PNG 是交付导出。原始概念图由内置图像生成工具生成；SVG 按所选方向重新绘制，统一为纯色几何路径，不是位图嵌入。重建后的细节以 SVG 为准。标志图形不依赖字体、外链或脚本；横向组合的文字保留可编辑 text，使用 Arial / PingFang SC / sans-serif 回退，不捆绑字体，跨平台字形可能略有差异，需要固定外观时使用 PNG。

## 使用规范

- 主色 `#3361BD`；辅助青 `#48BFC0`；深色 `#202F40`。
- 保持比例；四周保留至少标志宽度 1/10 的空白。SVG 已留出边距。
- 独立标志建议显示宽度至少 32 px；16 / 24 px 的导航或页签优先使用应用图标，细线在小尺寸下会自然简化。
- 深背景使用反白版，浅背景使用彩色或深色单色版；不额外添加渐变、阴影或描边。
- 界面中的 img 设置有意义的 alt；若旁边已有软件名称，则使用空 alt 避免重复朗读。
- 接入 React 时通过构建工具导入 SVG；不要引用开发者机器的绝对路径。打包资源应包含在应用内，不依赖联网加载。
- 目前只交付品牌资源及 README 展示。工作台导航、HTML 原型、Electron 窗口和安装包图标尚未接入；接入时应从本目录复用，不另画近似图。ICNS / ICO 与打包配置留给桌面打包阶段。

## 设计来源与维护

初始生成提示要点：FolioTrace / 文脉；叠放文稿组成抽象 F；双节点连接表示版本轨迹；简约蓝色、少量青色；可在应用图标尺寸识别；避免 AI 星芒、立体效果和复杂电路。使用内置图像生成工具，未使用第三方图标库作为品牌标志。

本目录沿用仓库 MIT 许可。修改 SVG 后同步导出 PNG，检查 16 / 32 / 128 px 和深浅背景，必要记录写入软件 CHANGELOG 的 Unreleased，不因图标变更单独升级软件版本。
