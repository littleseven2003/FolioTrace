# 单阶段开发模板

阶段：<M2 / M3 / M4 / M5 / M6>
本轮目标：<从 docs/05-roadmap.md 复制一个可验收目标>

读取根 AGENTS.md、docs/STATUS.md 及此阶段需要的需求/协议/测试文档；git status 后确认工作边界。先列将修改的模块、需要验证的不变量、验收步骤，再执行。

严格遵循已确定的数据协议和类型边界；有必要调整协议时同时更新 schema、样例与测试，写清兼容性。不要夹带下一阶段，不重写已确认 UI。所有文件操作用合成样例的临时副本。

完成后运行本阶段检查，核对 diff，更新 STATUS/CHANGELOG，提交一个可审查的小变更。最终给出：完成点、验证结果、未完成项、下一步。无法证明的行为不要宣称可用。

## 提交要求

每完成并验证一个独立小改动，立即本地 commit，再开始下一项；不要积累到阶段末。标题严格使用 `英文类型：中文描述`（中文全角冒号，无 scope），例如 `docs：补充任务验收说明`。只暂存本次相关改动，保留他人工作。评审若没有修改文件，不制造空提交。版本号按 docs/09-versioning.md 编排，不随每个 commit 自动递增。
