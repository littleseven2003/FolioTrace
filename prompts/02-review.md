# 阶段评审

请评审当前分支相对 main 的变化。先读取 AGENTS.md 和本阶段需求，不先改代码。

优先检查：实际验收是否达到；renderer 是否获得过宽文件能力；路径越界；事件重入/部分导入；父版本与配套端点；原地修改是否伪造旧快照；是否偷偷改变当前采用；任务输入是否固定；测试是否验证行为；真实数据与凭据是否误入仓库。

只报告有依据、可复现的问题，包含严重度、文件位置、触发场景、影响与最小修复方向。没有问题时说明验证范围和未测环境，不编造发现。获得当前任务授权后再修复并运行针对性验证。

## 提交要求

每完成并验证一个独立小改动，立即本地 commit，再开始下一项；不要积累到阶段末。标题严格使用 `英文类型：中文描述`（中文全角冒号，无 scope），例如 `docs：补充任务验收说明`。只暂存本次相关改动，保留他人工作。评审若没有修改文件，不制造空提交。版本号按 docs/09-versioning.md 编排，不随每个 commit 自动递增。
